# 🤝 Помощь Рядом

Гиперлокальный P2P маркетплейс бытовых услуг с фокусом на доступность для пожилых людей.

## 📋 Описание проекта

**Помощь Рядом** — это веб-приложение, которое соединяет заказчиков и исполнителей бытовых услуг в одном районе. 

### Главные особенности:
- 📍 **Гиперлокальность**: работа только в пределах одного района
- 📞 **Без чатов**: прямые звонки после оплаты 50₽ за доступ к номеру
- 👴 **Доступность для пожилых**: крупный шрифт, голосовой ввод
- ⚡ **Простота**: минималистичный интерфейс без лишних функций

## 🛠 Технический стек

- **Backend**: Python 3.10+, Flask 3.0
- **Database**: SQLite (для MVP)
- **Frontend**: HTML5, CSS3 (без фреймворков), Vanilla JS
- **Authentication**: Flask-Login
- **Payments**: QR-коды СБП

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
cd /workspace/pomosh_ryadom
pip install -r requirements.txt
```

### 2. Запуск приложения

```bash
python3 app.py
```

Приложение будет доступно по адресу: **http://127.0.0.1:5000**

### 3. База данных

База данных создаётся автоматически при первом запуске.

## 📊 Модели данных

### User (Пользователь)
- `id` — уникальный идентификатор
- `name` — имя пользователя
- `phone` — номер телефона (уникальный)
- `password_hash` — хеш пароля
- `role` — роль ('customer', 'executor', 'both')
- `district` — район
- `latitude`, `longitude` — координаты
- `rating` — рейтинг (по умолчанию 5.0)
- `completed_tasks` — количество выполненных заданий
- `is_verified` — верифицирован ли пользователь

### Task (Задание)
- `id` — уникальный идентификатор
- `user_id` — создатель задания
- `title` — название задания
- `description` — описание
- `category` — категория ('уборка', 'доставка', 'мастер' и т.д.)
- `price` — цена
- `address` — адрес
- `district` — район
- `urgency` — срочность ('срочно', 'планово', 'навыки')
- `status` — статус ('active', 'completed', 'cancelled')
- `phone_hidden` — маскированный телефон
- `executor_id` — исполнитель (после принятия)

### Payment (Платёж)
- `id` — уникальный идентификатор
- `task_id` — задание
- `executor_id` — исполнитель
- `amount` — сумма (по умолчанию 50₽)
- `qr_code_path` — путь к QR-коду
- `status` — статус ('pending', 'paid')

## 🎨 Дизайн-система

### Цвета
- `--primary-green: #4CAF50` — основной зелёный
- `--primary-blue: #2196F3` — основной синий
- `--warning-yellow: #FFC107` — предупреждение
- `--danger-red: #F44336` — опасность
- `--text: #212121` — текст
- `--text-secondary: #757575` — вторичный текст

### Шрифты
- Базовый размер: **18px**
- Заголовки: **24-28px**
- Кнопки: **20px**

### Режим для пожилых
- Базовый шрифт: **24px**
- Кнопки: **60px высотой**
- Класс: `.elderly-mode`
